# Замер скорости скачивания

Консольная программа на Python: последовательно скачивает файл по URL и показывает время запросов, объём данных и среднюю скорость.

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в папке проекта и выполните:

```bash
python main.py "https://адрес-файла"
```

В Windows команда может выглядеть так:

```powershell
py .\main.py "https://адрес-файла"
```

Укажите прямую ссылку на скачиваемый файл, например изображение. По умолчанию программа скачивает его 10 раз; тайм-аут каждого запроса — 30 секунд.

Чтобы изменить параметры, укажите количество запросов и тайм-аут в секундах:

```bash
python main.py "https://адрес-файла" --count 5 --timeout 60
```

## Результат

После каждого запроса выводятся его длительность и размер ответа. В конце показываются среднее время запроса, суммарный объём скачанных данных и средняя скорость в Мбит/с и МБ/с. Скорость считается по общему объёму и времени всей серии запросов.
